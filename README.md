# Data Science Playbook for Researchers

A guide to coding as a researcher: learning path, R and Python data work, Git, the command line, ML, Bayesian inference, and useful tools.

**Read it: [playbook.pdf](playbook.pdf)**

## Origin

This content was originally published as a website at **bmanuelpillai.github.io** (repo [`bmanuelpillai/bmanuelpillai.github.io`](https://github.com/bmanuelpillai/bmanuelpillai.github.io)). It was converted to Markdown + PDF here; the git history of the original site is kept in this repo.

## Editing

Source lives in `chapters/` (one Markdown file per chapter, built in filename order). Rebuild the PDF with:

```sh
./build.sh   # needs pandoc and xelatex
```

`files/` holds my VS Code keyboard shortcuts and settings referenced in the toolbox chapter.

Feel free to open an issue or contribute.
