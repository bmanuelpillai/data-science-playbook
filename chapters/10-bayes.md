# Getting Started with Bayesian Inference

*Modeling Framework*

## Recommended Resources to Learn Bayesian Inference

### Learn Theoretical Basis

This textbook builds up your understanding of Bayesian inference from fundamental principles of probability without getting too deep into the math. I recommend starting here and then quickly applying what you learn to your own data.\
[*A Student's Guide to Bayesian Statistics* by Ben Lambert](https://ben-lambert.com/a-students-guide-to-bayesian-statistics/)

### Introduction to Stan in R

Once you have a grasp of how Bayesian inference works, it's time to apply those methods to your own data. I recommend watching this video for an introduction to using Stan in R to implement Bayesian methods. Stan is a probabilistic programming language that lets you write and fit statistical models.\
[Bayesian Modeling with Stan and R](https://www.youtube.com/watch?v=QqwCqPYbatA)

If you'd rather not write Stan code directly, the [`brms`](https://paul-buerkner.github.io/brms/) package lets you fit Stan models using familiar R formula syntax.

### Introduction to NumPyro in Python

I recommend spending some time reading through the NumPyro documentation and then following along with the introductory tutorials.\
[NumPyro documentation](https://num.pyro.ai/en/stable/index.html)
