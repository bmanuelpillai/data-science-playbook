# Further Learning

*Useful Courses and Fun Content*

## Useful Courses

| Name | Description |
|----|----|
| [Statistical Programming in R](https://american-stat-412612.netlify.app/) | Introductory course teaching you the basics of using the tidyverse for data analysis |
| [Kelsey Codes (YouTube)](https://www.youtube.com/playlist?list=PL6FsZxVq54ERrlMRNE5aq2qUFH042fbuM) | Video series that goes along with the course above |
| [R for Data Science](https://r4ds.hadley.nz/) | Free book on data analysis with the tidyverse |
| [Data Wrangling in Python](https://sscc.wisc.edu/sscc/pubs/dwp/) | Teaches data wrangling in Python using pandas |
| [Atlassian Git Tutorials](https://www.atlassian.com/git/glossary#commands) | Reference for common Git commands |
| [Advanced R](https://adv-r.hadley.nz/) | Deep dive into advanced R programming concepts |
| [R Packages (2e)](https://r-pkgs.org/) | Guide to creating and maintaining R packages |
| [The Missing Semester of Your CS Education](https://missing.csail.mit.edu/) | Practical tools CS courses skip: the shell, editors, Git, and debugging |
| [Grokking Algorithms](https://github.com/swadhinsekhar/books/blob/master/Grokking%20Algorithms%20-%20An%20illustrated%20guide%20for%20programmers%20and%20other%20curious%20people.pdf) | Illustrated guide to understanding algorithms |
| [Scikit-Learn ML from Start to Finish (Kaggle)](https://www.kaggle.com/code/enerrio/scikit-learn-ml-from-start-to-finish) | Machine learning tutorial using scikit-learn, from start to finish |
| [StatQuest Machine Learning (YouTube)](https://www.youtube.com/playlist?list=PLblh5JKOoLUICTaGLRoHQDuF_7q2GfuJF) | Clear, visual explanations of machine learning concepts |
| [QCBS R Workshop Series](https://r.qcbs.ca/workshops/) | Useful for learning cluster analysis, GAMs, GLMs, etc. |
| [Bayes Rules!](https://www.bayesrulesbook.com/) | Free introductory book on Bayesian modeling in R |
